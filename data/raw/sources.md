# Primary Sources

This file lists sources that were directly pulled or processed as data inputs 
for this project's scripts, in place of committing raw PDFs/HTML/full-text 
extractions to the repository. Sources cited only in the written report's 
footnotes (not used as a data input) are referenced there and not duplicated 
here.

All sources listed are publicly available government or institutional 
publications. Scripts in `src/data_sourcing/` were used to pull, verify, and 
extract data from these sources.

Each entry includes the official URL and the date it was accessed, so the 
underlying data can be independently re-pulled and checked against this 
project's extracted figures.

## Notes on reproducibility

- NICE appraisal documents are Crown copyright and reproduced here only by 
  reference/link, consistent with NICE's terms of use for non-commercial reuse.
- CMS/HCPCS documents are US government works and are generally in the public domain.
- Full plain-text extractions of the NICE appraisals (used as input to 
  `src/analysis/theme_extraction.py` and related scripts) are not committed to 
  this repository for the same reason. They can be regenerated by running 
  `src/data_sourcing/extract_nice_pdfs.py` against the PDF versions of the TAs 
  listed above.
- Where a source URL has since changed or been superseded (e.g. NICE guidance 
  pages are occasionally restructured), the access date above reflects the 
  version the data in this repository was extracted from.
